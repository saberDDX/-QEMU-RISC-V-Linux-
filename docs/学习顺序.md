# 最短学习顺序

完整主资料：[项目完整流程与学习路线](项目完整流程与学习路线.md) → [关键代码逐段讲解](关键代码逐段讲解.md) → [项目八股问答](项目八股问答.md)。先讲通主线，再读代码，再动手验证，最后用一页卡复习。

1. 先看 README 的启动命令，自己启动一次。遇到提示后按回车进入 Shell。
2. 在目标 Shell 执行 `uname -m`、`uname -r`、`cat /proc/cmdline`，区分宿主与目标。
3. 读 `configs/boot.cmd`，指出 root、console、loglevel；与 baseline 文件比较。
4. 读 `app/bsp_demo.c`，说清 uname 系统调用封装、/proc/uptime、一次性进程、退出码。
5. 在目标执行 `/usr/bin/bsp_demo manual`，再看开机输出中的 autostart。
6. 读 `rootfs/etc/inittab` 和 `rootfs/etc/init.d/rcS`，解释 PID 1 和为什么先 mount proc。
7. 看最终文件索引与日志，从启动链路逐层复述。每个答案指向一个实际文件或一段日志。

记住“谁运行、谁加载、数据在哪、怎样证明”。不需要逐行背上游源码。
