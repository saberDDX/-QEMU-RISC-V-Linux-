# 最小人工验收

这是操作清单，不是自动测试框架。结果必须以目标串口日志为准。

1. 宿主 `scripts/make-images.sh baseline` 后运行 `scripts/run.sh`，保存完整串口输出。
2. 等待开机自启动输出，按回车进入 Shell。执行：

```sh
uname -m
uname -r
cat /proc/cmdline
cat /proc/sys/kernel/printk
/usr/bin/bsp_demo manual
ps
poweroff
```

3. QEMU 退出后，宿主运行 `scripts/make-images.sh custom`，按同一入口重启并保存另一份日志，再做相同检查。
4. 比较两份日志：同一 riscv64 / Linux 6.1.11；cmdline 从 loglevel=7 改为 4；printk 第一项也相应改变；程序在手工命令前已有 autostart 输出，手工调用有 manual 输出；PID 1 为 init。
5. 最终保留 custom 镜像。曾经失败的日志单独保留，不混入成功结论；不要求性能指标、长期稳定性或额外功能测试。

root 和 console 保持相同。RC 初始化脚本不调用 `dmesg -n`，避免它再次覆盖本次测量的 loglevel。
