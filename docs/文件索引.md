# 关键文件索引

| 文件 | 用途 |
| --- | --- |
| configs/upstream.env | 官方仓库及固定源码提交 |
| scripts/env.sh | 当前云环境路径、工具链及构建参数 |
| scripts/build-qemu.sh | 构建含 quard-star 的 QEMU |
| scripts/build-newlib.sh | 为高地址固件构建 medany C 库 |
| scripts/build-firmware.sh | 上游 Mask ROM、lowlevelboot、trusted_domain、OpenSBI 与 DTB 构建 |
| scripts/build-uboot.sh | qemu-quard-star_defconfig 构建 |
| scripts/build-kernel.sh | quard_star_defconfig 构建 Linux Image |
| scripts/build-busybox.sh | 上游 BusyBox 配置与 CONFIG_TC 兼容调整 |
| scripts/make-images.sh | 集成程序、目标库、初始化文件并制作文件系统 |
| scripts/pack-images.py | 普通文件中的固件布局和 MBR 分区组装 |
| scripts/run.sh | 无图形串口启动入口 |
| scripts/run-debug.sh | 增加 -S 与本机 GDB 接口的调试启动入口 |
| scripts/debug-kernel.sh | 加载匹配 vmlinux 并连接 QEMU 的 GDB 入口 |
| configs/boot.baseline.cmd | loglevel=7 的基线启动脚本 |
| configs/boot.cmd | loglevel=4 的定制启动脚本 |
| app/bsp_demo.c | 本项目 C 程序源码 |
| rootfs/etc/inittab | BusyBox init 的实际配置 |
| rootfs/etc/init.d/rcS | 挂载系统设施并执行 bsp_demo autostart |
| rootfs/etc/profile | 交互 Shell 的 PATH 和提示符 |
| output/images/Image | 从源码构建的 Linux 内核 |
| output/images/quard_star_uboot.dtb | 复用 DTS 构建的 U-Boot/Linux 硬件描述 |
| output/images/fw_jump.bin | OpenSBI 固件 |
| output/images/u-boot.bin | U-Boot 引导程序 |
| output/images/disk.img | FAT32 启动分区与 ext4 根分区的磁盘镜像 |
| output/rootfs | 宿主上的目标文件系统暂存目录，尚非正在运行的系统 |
| output/build | 各组件编译中间产物 |
| output/logs | 当前构建及辅助串口日志 |
| evidence | 目标系统的真实验收结果 |

上游源码位于 `/workspace/quard-star-upstream`，是完整下载并校验后的源码归档，不是 Git checkout。本项目 Git 仓库只保存自己的脚本、配置、应用与文档，避免提交数 GB 上游源码和生成产物。
